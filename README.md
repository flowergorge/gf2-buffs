# 흙먼지 버프 도감

한국·중국 서버의 시즌 효과와 1~7일차 버프를 표시하는 정적 웹사이트입니다.

## 서버별 데이터

- 한국: `data.json`, KST(UTC+9)
- 중국: `data-cn.json`, 중국 시간(UTC+8)
- 웹 상단의 서버 선택으로 전환합니다. 중국 바로가기: `?server=cn`
- 서버 데이터를 합치지 않습니다. 첫 로딩마다 해당 서버의 오늘 시즌/일차를 선택합니다.
- 진행 중인 1~7일차가 없으면 최근 시작한 시즌의 전체 일차를 표시합니다.

## PC 뷰어 v4로 게시

1. GitHub 연결 설정에서 fine-grained token을 등록합니다. 이 저장소의 Contents: Read and write 권한이 필요합니다.
2. kr 또는 cn 서버를 선택하고 해당 클라이언트 Table 폴더를 불러옵니다.
3. 한국 전체 시즌 업데이트 / 중국 전체 시즌 업데이트를 누릅니다.
4. main 브랜치의 해당 JSON이 갱신되고 GitHub Pages 배포 후 반영됩니다.

게시 버튼은 검색/일차 필터와 무관하게 전체 시즌 효과·일정·버프를 포함합니다.
같은 데이터로 반복 게시하면 새 커밋을 만들지 않습니다.
토큰은 사용자 PC의 Windows 자격 증명 관리자에만 보관합니다.
PC 뷰어 소스와 실행 파일은 이 정적 사이트에 포함하지 않습니다.

수동으로 갱신할 때는 서버 ID가 kr 또는 cn인 게시용 JSON을 해당 파일명으로 업로드하세요.
`preview_only: true` 파일은 웹의 로컬 파일 미리보기로만 읽을 수 있습니다.
구버전 배열 형식과 단일 시즌 파일도 로컬 미리보기에서는 지원됩니다.
선택한 미리보기 파일은 서버로 전송되지 않습니다.

## 표시 기준

클라이언트에 저장된 설정이며 서버 실제 적용 여부는 검증하지 않았습니다.
날짜는 시즌 시작 시각부터 24시간 단위로 계산합니다.
8일차 이후는 화면에서 제외합니다. JSON 제한은 12MB / 30,000행입니다.

## Pages

Settings → Pages → Deploy from a branch → main / (root)
index.html, style.css, app.js, data.json, data-cn.json을 같은 폴더에 둡니다.
