# 흙먼지 버프 도감

소녀전선2 흙먼지의 시즌/그룹별 버프를 확인하는 비공식 정적 웹사이트입니다.
1~7일차만 표시하며, 이름·효과·ID 검색과 로컬 JSON 미리보기를 지원합니다.
별도 패키지 설치나 빌드 없이 GitHub Pages에서 실행됩니다.

## 데이터 업데이트

1. GF2BuffViewer에서 원하는 시즌을 선택합니다.
2. 일차를 **전체**로 설정하고 검색어를 비웁니다.
3. **현재 목록 JSON 저장**으로 내보내고 파일명을 `data.json`으로 맞춥니다.
4. 이 저장소 최상위에서 **Add file → Upload files**로 새 `data.json`을 올립니다.
5. **Commit changes**로 저장합니다.
6. Pages 배포가 완료되면 사이트에서 **데이터 새로고침**을 누릅니다.

처음 포함된 파일은 2026-09-22에 추출한 시즌 31입니다. 새 시즌은 자동으로 내려받지 않습니다.
원본 JSON의 8일차 이후 데이터는 수정하지 않으며 화면에서 제외합니다.
EXE는 현재 필터에 표시된 행만 내보내므로 저장 전에 일차와 검색 필터를 확인하세요.
내보낸 JSON의 `source` 항목은 사이트에서 사용하지 않으므로 공개 전에 제거해도 됩니다.

## JSON 형식

기존 프로그램의 `{ "region": "kr", "season": {...}, "buffs": [...] }` 형식과 버프 배열을 지원합니다.
여러 시즌의 메타데이터는 `seasons` 배열로 제공할 수 있습니다.
시즌 메타데이터가 없는 파일은 그룹 번호와 일차만 표시합니다.
JSON 파일은 12MB 이하, 30,000행 이하를 지원합니다.

## 표시 기준

데이터는 설치된 클라이언트의 설정이며 서버 실제 적용 여부는 검증하지 않았습니다.
날짜는 시즌 시작 시각으로부터 24시간 단위로 계산하고 한국 시간(KST)으로 표시합니다.
사이트의 JSON 미리보기 기능은 브라우저에서만 동작하며 서버 데이터를 바꾸지 않습니다.

## Pages 설정

Settings → Pages → Deploy from a branch → `main` / `/(root)`.
`index.html`, `style.css`, `app.js`, `data.json`을 같은 폴더에 둡니다.
